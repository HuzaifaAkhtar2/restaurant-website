# Britannia Restaurant Website

A responsive restaurant website built for Britannia Restaurant.

The website provides information about the restaurant, its menu, services, opening hours, and contact details.

## Features

- Responsive design for desktop, tablet, and mobile
- Restaurant menu
- About section
- Contact information
- Opening hours
- Customer testimonials
- Mobile navigation
- Basic SEO and structured data

## Built With

- HTML5
- CSS3
- JavaScript
- Remix Icons

## Pages

- Home
- Menu

## Project Purpose

This website was created as a client project to provide Britannia Restaurant with a simple and responsive online presence where customers can learn about the restaurant and view its menu.
